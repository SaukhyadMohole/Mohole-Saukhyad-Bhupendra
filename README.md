# Exploratory Data Analysis (EDA) – Phase 1

This repository contains the Phase 1 course project for **BCSE331P – Exploratory Data Analysis**.

## Dataset
- **Dataset:** Fishing.csv

## Project Tasks
The following Exploratory Data Analysis (EDA) tasks were performed:

- Loading the dataset
- Basic statistical analysis
- Handling missing values
- Data cleaning
- Data transformation
- Univariate analysis
- Bivariate analysis
- Multivariate analysis

## Repository Contents

- `EDA_Phase1_Fishing.ipynb` – Google Colab notebook containing the complete EDA.
- `Fishing.csv` – Dataset used for analysis.
- `README.md` – Project overview.
